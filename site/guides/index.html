Codex and Claude Code usage limit guides

OpenAI Codex and Anthropic’s Claude Code both cap usage over a few hours and over the week. These guides explain how each limit works, where to see what is left and when it resets, and what to do when you run out. Each one is checked against the official OpenAI or Anthropic documentation and links to it.

  • Codex usage limits: 5-hour and weekly limits explained

    The Codex allowances on each ChatGPT plan, how to check remaining usage and the reset time, and your options when you hit the limit.

  • Claude Code usage limits: 5-hour and weekly limits

    The five-hour session limit and weekly limit on Pro, Max and Ultra, when they reset, and how to check them with /usage or the status line.

  • Codex reset credits: how banked resets work

    What a banked Codex reset restores, when it expires, how to redeem it and when using one is worth it.
