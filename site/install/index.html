Install Codex Tracker

The simplest way: ask your coding agent. Codex Tracker installs for the current Windows user in under a minute, with no admin rights.

1. Ask Codex (recommended)

Paste this sentence into Codex, Claude Code or any coding agent that can run commands on your PC:

Install Codex Tracker on this PC by following https://codex-tracker.zqsdev.com/install/

The agent reads this page, runs the installer command below and tells you when the icon is next to the clock. It may ask you to approve the command first.

2. Or run one command

In PowerShell (Windows 11, 64-bit):

irm https://codex-tracker.zqsdev.com/install.ps1 | iex

It downloads the latest release from GitHub, checks its SHA-256, installs it for your user only and starts it. Read the script before running it if you like.

3. Or download the installer

Download Codex Tracker {{VERSION}}

A portable ZIP is on the releases page. The executables are not code-signed, so SmartScreen may warn on first launch: choose “More info → Run anyway”.

After installing

  • Keep using Codex or Claude Code as usual: the signed-in account appears by itself.
  • Drag the icon out of the taskbar’s ^ overflow to keep the percentage visible.
  • Updates install themselves.

For AI coding agents

You were asked to install Codex Tracker for the user. Follow these steps exactly and report the result.

  1. Check the machine runs Windows 11, 64-bit. Codex Tracker does not run on macOS or Linux; say so and stop.
  2. Run, in a shell with network access (ask the user for approval if your sandbox requires it): 
    powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://codex-tracker.zqsdev.com/install.ps1 | iex"
  3. The command prints Codex Tracker: version X installed and running (or that it is already installed). Report the version to the user and tell them to drag the icon out of the taskbar’s ^ overflow.
  4. Optional, only if the user wants their agent to read quotas: ask them to turn on Settings → Assistants in Codex Tracker (off by default; you cannot do it for them). Then register the MCP server, for example: 
    codex mcp add codex-tracker -- "%LOCALAPPDATA%\Programs\CodexTracker\CodexTracker.exe" --mcp
claude mcp add codex-tracker -- "%LOCALAPPDATA%\Programs\CodexTracker\CodexTracker.exe" --mcp
    The same commands also work without MCP: "%LOCALAPPDATA%\Programs\CodexTracker\CodexTracker.exe" --cli help (JSON output).
  5. Do not change Codex or Claude settings, accounts or sessions. Codex Tracker only reads the quota data they already store.
