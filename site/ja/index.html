インストール方法は3つ、どれも無料です。いちばん早いのは、コーディングエージェントに任せる方法です。

CodexとClaude Codeの使用制限を見える化

OpenAI CodexとAnthropicのClaude Codeには、5時間単位と週単位の2つの使用制限があります。使い切ると回復を待つしかなく、どちらのツールも複数アカウントの状況をはっきりとは示してくれません。Codex Trackerは、3つの疑問にひと目で答えます。

あとどれくらい残っている？

残りの割合をタスクバーのアイコンに直接表示します。マウスを重ねると、アクティブなアカウントの両方の制限を確認できます。

いつリセットされる？

すべてのアカウントの各制限について、正確なリセット時刻を一覧または週間カレンダーで表示します。

どのアカウントを使うべき？

個人用も仕事用も、CodexとClaude Codeのすべてのアカウントを並べて表示。それぞれ最後に読み取った日時付きです。

クイックツアー

アカウント、リセットの週表示、リマインダー、ライトテーマ、アシスタントを12秒で。デモアカウントのみを使用しています。

クォータに関することを、すべてここに

アカウントをひと目で

アクティブなアカウントはリング、その他はバーで表示し、各読み取りからの経過時間も示します。非アクティブなアカウントは最後の値を保持し、リセット時刻を過ぎると「おそらく回復済み」と表示されます。

切り替え先のアカウントを提案

使用中のアカウントが10%以下になると、通知とトレイアイコンのツールチップで、同じツールの別のアカウントのうち、残りが30%以上かつ20ポイント以上多いものを示します。アカウントを勝手に切り替えることはありません。

詳細と履歴

各アカウントは最大90日分の読み取りをローカルに保存します。24時間または7日間の残りクォータの推移、保存済みリセット、契約期間、最近のペースで使い切る時期の控えめな見積もりを確認できます。

リセットカレンダーと保存済みクレジット

今後のリセットを日ごとに表示し、Codexのリセットクレジットも有効期限とともに確認できます。新しいクレジットが付与されると通知し、使わないまま期限切れになる前に使うよう提案します。

GoogleカレンダーとGmailをワンクリックで

Googleカレンダーを接続すると、保存済みのリセットクレジットがリマインダー付きでカレンダーに追加され、使用すると削除されます。クレジットの期限の前日には、ご自身のGmailからメールが届きます。

どのサイズでも読みやすい

割合と細いゲージを、タスクバーアイコンの実際のサイズにピクセル単位で合わせて描画します。ライトでもダークでも鮮明です。マウスを重ねるとプレビューが開き、そこでクォータをクリックするとアイコンに表示できます。両方のツールを使うなら、ツールごとにアイコンを表示できます。

よくある質問

ほかに質問があればGitHubでどうぞ。

Codexの残り使用量はどうやって確認できますか？

WindowsにCodex Trackerをインストールし、Codexをいつもどおり使うだけです。トレイアイコンにアクティブなアカウントの残りの割合が表示され、マウスを重ねると5時間制限と週間制限、次のリセット時刻を確認できます。

Codexの週間制限はいつリセットされますか？

リセット時刻はCodexのアカウントごとに異なります。Codex TrackerはCodex自体からその時刻を読み取り、すべてのアカウントについて正確な日時を一覧または週表示で示します。リマインダーも設定できます。

Claude Codeにも対応していますか？

はい。Claudeデスクトップアプリは自動で検出されます。ターミナルでClaude Codeを使う場合は、Settings → General → Claude Code に表示されるステータスライン設定をコピーしてください。

Codexのリセットクレジットとは何ですか？

Codexでは、好きなときに制限を回復でき、一定期間で失効するリセットクレジットが付与されることがあります。Codex Trackerはそれらを有効期限とともに一覧表示し、新しく付与されたときに通知し、Googleカレンダーに追加でき、無駄になる前に使うよう提案します。

開いているアカウントだけが更新されるのはなぜですか？

トラッカーはCodexとClaudeでアクティブなアカウントを読み取ります。ほかのアカウントは、再び開くまで最後に読み取った値を日時付きで保持します。

起動したままにしておく必要がありますか？

リマインダーを使うなら必要です。タスクバーで目立たずに動作し、Windowsと同時に起動できます。PCの電源が入っている必要があります。

Codex Trackerは無料で、プライバシーは守られますか？

はい。無料のオープンソース（MIT）です。登録もサーバーもありません。CodexとClaudeがすでにPC上で把握しているクォータを読み取るだけで、会話やパスワードを読むことはありません。任意のSMS、電話、SendGridのメールだけは、ご自身のプロバイダーアカウントを通じて送信され、その料金がかかります。

OpenAIやAnthropicと提携していますか？

いいえ。Codex Trackerは独立したプロジェクトです。CodexとClaudeは、それぞれの所有者の商標です。

制限を理解する

各制限のしくみ、残りの確認方法、使い切ったときの対処を、OpenAIとAnthropicの公式ドキュメントに照らして解説します。ガイドは英語です。

  • Codexの使用制限

    5時間と週間の枠、残りの確認方法、リセットのタイミング。

  • Claude Codeの使用制限

    ProとMaxのセッション制限と週間制限、その確認方法。

  • Codexのリセットクレジット

    保存済みリセットとは何か、いつ期限が切れ、いつ使うべきか。
