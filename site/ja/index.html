CodexとClaude Codeの残り使用量を、いつでも把握

Codex Trackerは、5時間と週間の使用制限をWindowsのタスクバーに表示し、それぞれがいつリセットされるかを正確に伝え、最適なタイミングでお知らせします。アカウントもサーバーも設定も不要です。

CodexとClaude Codeの使用制限を見える化

OpenAI CodexとAnthropicのClaude Codeには、5時間単位と週単位の2つの使用制限があります。使い切ると回復を待つしかなく、どちらのツールも複数アカウントの状況をはっきりとは示してくれません。Codex Trackerは、3つの疑問にひと目で答えます。

あとどれくらい残っている？

残りの割合をタスクバーのアイコンに直接表示します。マウスを重ねると、アクティブなアカウントの両方の制限を確認できます。

いつリセットされる？

すべてのアカウントの各制限について、正確なリセット時刻を一覧または週間カレンダーで表示します。

どのアカウントを使うべき？

個人用も仕事用も、CodexとClaude Codeのすべてのアカウントを並べて表示。それぞれ最後に読み取った日時付きです。

クォータに関することを、すべてここに

アカウントをひと目で

アクティブなアカウントはリング、その他はバーで表示し、各読み取りからの経過時間も示します。非アクティブなアカウントは最後の値を保持し、リセット時刻を過ぎると「おそらく回復済み」と表示されます。

リセットカレンダーと保存済みクレジット

今後のリセットを日ごとに表示し、Codexのリセットクレジットも有効期限とともに確認できます。新しいクレジットが付与されると通知し、使わないまま期限切れになる前に使うよう提案します。

GoogleカレンダーとGmailをワンクリックで

Googleカレンダーを接続すると、保存済みのリセットクレジットがリマインダー付きでカレンダーに追加され、使用すると削除されます。クレジットの期限の前日には、ご自身のGmailからメールが届きます。

ちょうどいいリマインダー

リセット前、残り20・10・5 %を下回ったとき、使い切る前、別のアカウントが回復した可能性があるときにお知らせします。標準はWindows通知。ご自身のTwilioまたはSendGridアカウントで、SMS、電話、メールにも対応します。

コーディングアシスタント向け

ローカルMCPサーバー（既定では無効）を使うと、コーディングエージェントがクォータを読み取り、リセットに合わせて計画を立て、設定を変更できます。外部に関わる操作にはローカルでの確認が必要です。

控えめでネイティブ

Windowsに合わせたライト／ダーク表示、英語またはフランス語、Windowsと同時に起動、自動更新。ウィンドウを閉じても時計の横に常駐します。

3ステップでインストール

  1. インストーラーをダウンロードして実行します。管理者権限は不要で、ほかにインストールするものもありません。
  2. CodexやClaude Codeをいつもどおり使います。サインイン中のアカウントは自動で表示され、ほかのアカウントは開いたときに追加されます。
  3. アイコンを常に表示するには、タスクバーの ^（隠れているインジケーター）から外へドラッグします。

インストーラーを使いたくない場合は、リリースページにポータブル版のZIPがあります。実行ファイルにはコード署名がないため、初回起動時にSmartScreenの警告が表示されることがあります。

データはあなたのPCにとどまります

登録もサーバーも不要

すべてローカルに保存されます。任意で設定するシークレットはWindows DPAPIで暗号化されます。

パスワードは不要

CodexとClaudeがすでに把握しているクォータを読み取るだけです。会話を読むことも、勝手にアカウントを切り替えることもありません。

必要最小限の通信

GitHubでの更新確認と、公開されているリセットのお知らせの取得のみで、どちらも任意です。Googleは接続した場合にのみ使われます。

よくある質問

Codexの残り使用量はどうやって確認できますか？

Codex Trackerをインストールし、Codexをいつもどおり使うだけです。トレイアイコンにアクティブなアカウントの残りの割合が表示され、マウスを重ねると5時間制限と週間制限、次のリセット時刻を確認できます。

Codexの週間制限はいつリセットされますか？

リセット時刻はアカウントごとに異なります。Codex TrackerはCodexからその時刻を読み取り、すべてのアカウントについて正確な日時を表示します。リマインダーも設定できます。

Claude Codeにも対応していますか？

はい。Claudeデスクトップアプリは自動で検出されます。ターミナルでClaude Codeを使う場合は、Settings → General → Claude Code に表示されるステータスライン設定をコピーしてください。

Codexのリセットクレジットとは何ですか？

Codexでは、好きなときに制限を回復でき、一定期間で失効するリセットクレジットが付与されることがあります。Codex Trackerはそれらを有効期限とともに一覧表示し、付与されたときに通知し、Googleカレンダーに追加して、無駄になる前に使うよう提案します。

開いているアカウントだけが更新されるのはなぜですか？

トラッカーはCodexとClaudeでアクティブなアカウントを読み取ります。ほかのアカウントは、再び開くまで最後に読み取った値を日時付きで保持します。

起動したままにしておく必要がありますか？

リマインダーを使うなら必要です。タスクバーで目立たずに動作し、Windowsと同時に起動できます。PCの電源が入っている必要があります。

無料ですか？

はい。MITライセンスの無料オープンソースです。任意のSMS、電話、SendGridのメールだけは、ご自身のプロバイダーアカウントを通じて送信され、その料金がかかります。
