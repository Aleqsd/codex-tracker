# Icônes des fournisseurs

Ces PNG sont les icônes officielles des applications Windows, copiées sans modification depuis leurs paquets Microsoft Store. Elles identifient les comptes suivis ; elles ne désignent pas Codex Tracker comme un produit des fournisseurs.

- `codex-dark.png` : OpenAI Codex 26.930.7945.0, `Assets/Square44x44Logo.targetsize-64_altform-unplated.png`.
- `codex-light.png` : même paquet, variante `lightunplated` officielle.
- `claude.png` : Claude 2.26454.0.0, `assets/Square44x44Logo.targetsize-64.png`.

Les noms et visuels restent la propriété d’OpenAI et d’Anthropic, hors licence MIT du code de ce dépôt. Ne pas les redessiner ni les recolorer. Voir [Codex](https://openai.com/codex/), [directives OpenAI](https://openai.com/brand/) et [Claude Desktop](https://claude.com/download).
